# Healthcare Data Analysis

## Project Overview
This project analyzes hospital patient data to identify trends in medical conditions, billing amounts, admission types, and test results. The analysis helps improve healthcare decision-making and resource management.

## Dataset
Source: Kaggle  
Rows: 1000+  
Columns: 16

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Dashboard Visualization

## Methodology
1. Data Loading
2. Data Cleaning and Processing
3. Feature Engineering (Length of Stay)
4. Data Analysis using Pivot Tables
5. Dashboard Creation

## Dashboard Insights
- Billing Amount by Medical Condition
- Length of Stay by Condition
- Admission Type Distribution
- Test Results by Condition
- Insurance Provider vs Billing

## Key Outcome
The analysis provides insights into hospital billing patterns, patient admission types, and test result distribution to support better healthcare decision-making.
